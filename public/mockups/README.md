# Wall mockup photos

`living-room.jpg` is the room picture the "on the wall" preview uses (supplied by the project
owner for development; check its licence before launch). The blank frame's rectangle, in the
picture's own pixels, is set in `src/features/poster/lib/wall-mockup.ts`; measure it again if
you replace the picture.

`living-room-wide.jpg` is the same kind of room with a wide frame, used for prints that are wider than
tall (the treasure map with a card for each moment). Its frame is set in the same file.
